# Contributing to tpt-asn1

This project does not accept pull requests. Contributions happen through
**issues only**.

## How to contribute

- **Bug reports** — open an issue with a minimal reproduction, the affected
  crate/version, and (if applicable) the malformed input that triggered it.
- **Feature requests** — open an issue describing the use case.
- **Vulnerabilities** — do **not** open a public issue. Follow the process in
  [SECURITY.md](SECURITY.md).

## Code of conduct

This project adheres to the [Code of Conduct](CODE_OF_CONDUCT.md). By
participating, you are expected to uphold it.
